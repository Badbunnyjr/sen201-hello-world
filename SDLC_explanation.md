# SDLC Explanation – Student Management System (SMS)

## Project: Student Management System (SMS)

### 1. Planning
- Build a system to store and display student information (name, matric number, course, level).

### 2. Requirements Analysis
- **Functional Requirements:** Add students, view students
- **Non-Functional Requirements:** Easy to use, command line

### 3. Design
- Data stored as a list of dictionaries
- Fields match exactly: name, matric_number, course, level

### 4. Implementation
- File: student_management.py

### 5. Testing
- Test by adding a sample student and viewing the list

### 6. Deployment
- Pushed to GitHub: sen201-student-management-system

### 7. Maintenance
- Future updates: delete/update students, GUI, file storage
